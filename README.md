# VEDA Technology - Task 2: Exploratory Data Analysis

## Project Overview

This project was completed as part of the VEDA Technology Data Analytics Internship.

The objective of this task is to perform Exploratory Data Analysis (EDA) on the Sample Superstore Dataset to identify important patterns, relationships, distributions, and business insights.

## Dataset

The analysis uses the Sample Superstore Dataset containing information related to:

- Sales
- Profit
- Quantity
- Discount
- Category
- Sub-Category
- Region
- Segment
- Ship Mode
- State
- City

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed

The following analysis was performed:

1. Dataset overview
2. Data cleaning
3. Missing value analysis
4. Duplicate record analysis
5. Descriptive statistics
6. Key business metrics
7. Sales analysis by category
8. Profit analysis by category
9. Sales analysis by region
10. Sales analysis by sub-category
11. Profit distribution analysis
12. Sales vs Profit analysis
13. Correlation analysis
14. Top sub-categories by sales
15. Top 3 business insights

## Visualizations

The project includes multiple visualizations:

- Total Sales by Category
- Total Profit by Category
- Total Sales by Region
- Total Sales by Sub-Category
- Profit Distribution
- Sales vs Profit Scatter Plot
- Correlation Heatmap
- Top 10 Sub-Categories by Sales

Each visualization includes a written observation.

## Key Insights

The analysis identifies important patterns in:

- Sales performance across categories and regions
- Profitability across categories
- Sales performance across sub-categories
- Relationship between sales and profit
- Distribution of profit values
- Relationships between numerical variables

## Conclusion

The Exploratory Data Analysis provides a clear understanding of the Superstore dataset and highlights important patterns in sales, profit, quantity, discount, categories, sub-categories, and regions.

The analysis demonstrates how data visualization and statistical analysis can be used to generate meaningful business insights and support data-driven decision making.
